# TP Sub Tailor (private beta)

Thanks for testing **TP Sub Tailor** by TP Designs!

## Download
Open **[Releases](../../releases/latest)** and download the `.zip` under *Assets*.

## Install in FL Studio (Windows 64-bit)
1. Unzip it and copy the **`TP Sub Tailor.vst3`** folder into `C:\Program Files\Common Files\VST3\`
2. In FL Studio: **Options > Manage plugins > Find installed plugins**
3. Load **TP Sub Tailor** from your Effects
